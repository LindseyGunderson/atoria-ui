# Dialog

The Dialog component presents important information or requests user input in a modal window. It provides an accessible, composable API built with React Context and supports keyboard interaction, overlay dismissal, and customizable layouts.

---

## Features

- Compound component API
- Accessible dialog semantics
- Keyboard support (Escape to close)
- Overlay click dismissal
- Multiple dialog sizes
- Close button support
- Flexible header and footer composition

## Usage

```tsx
<Dialog>
  <DialogTrigger>
    Open Dialog
  </DialogTrigger>

  <DialogContent>
    <DialogCloseButton />

    <DialogHeader>
      <DialogTitle>
        Delete account?
      </DialogTitle>

      <DialogDescription>
        This action cannot be undone.
      </DialogDescription>
    </DialogHeader>

    <DialogFooter>
      <DialogClose>
        Cancel
      </DialogClose>

      <Button variant="destructive">
        Delete
      </Button>
    </DialogFooter>
  </DialogContent>
</Dialog>
```

## Accessibility

The Dialog component follows accessible modal patterns by:

- Applying `role="dialog"` and `aria-modal="true"`
- Linking the dialog title and description using `aria-labelledby` and `aria-describedby`
- Closing when the **Escape** key is pressed
- Closing when the overlay is clicked
- Providing an accessible label for the close button

---

## Best Practices

- Keep dialog content concise and task-focused.
- Use clear, action-oriented button labels.
- Reserve dialogs for important actions or confirmations.
- Always provide a way to dismiss the dialog.
- Prefer confirmation dialogs for destructive actions.
