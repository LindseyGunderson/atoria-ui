# Typography

Atoria UI uses a dual typography system.

## Display Typeface

Instrument Serif is used for expressive moments:

- Marketing pages
- Hero sections
- Documentation headings


## Interface Typeface

Instrument Sans is used for:

- Components
- Body content
- Labels
- Navigation


## Typography Scale

The system uses a consistent scale to create hierarchy:

- xs
- sm
- md
- lg
- xl
- 2xl
- 3xl
- 4xl
