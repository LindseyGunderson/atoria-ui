# Color System

Atoria UI uses a warm, editorial-inspired color palette designed to
create interfaces that feel refined while maintaining accessibility.

The system is divided into three layers:

- Brand colors
- Neutral colors
- Semantic colors


## Brand

The primary brand palette uses deep burgundy tones.

Brand colors are used for:

- Primary actions
- Interactive states
- Brand moments


## Neutral

Warm neutrals create the foundation of the interface.

They are used for:

- Backgrounds
- Surfaces
- Text
- Borders


## Semantic Colors

Semantic colors communicate meaning rather than visual style.

Examples:

- Success
- Warning
- Error
- Information
