# Welcome to Atoria UI

Atoria UI is a React component library built around thoughtful design,
accessibility, and developer experience.

The system combines a warm editorial aesthetic with a practical,
scalable component architecture.

## Design Principles

### Accessible by Default

Components should provide accessible behavior and sensible defaults
without requiring additional configuration.

### Semantic Tokens

Design decisions are expressed through meaningful tokens rather than
hard-coded values.

### Consistent Experience

Spacing, typography, color, and interaction patterns should feel
intentional across every component.

### Composable APIs

Components should remain flexible and easy to extend.

## Technology

Atoria UI is built with:

- React
- TypeScript
- Tailwind CSS
- Storybook
- Class Variance Authority
